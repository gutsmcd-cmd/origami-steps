# おりがみステップ · Origami Steps

Step-by-step folding guides for 10 classic origami models (paper plane, cup, samurai helmet, boat, dog, cat, tulip, heart, jumping frog, crane), with simple SVG diagrams, Back/Next buttons and a Big steps mode.

日本語 default with an English switch, Large text option. No ads, no login, works offline (PWA).

Live: https://gutsmcd-cmd.github.io/origami-steps/
